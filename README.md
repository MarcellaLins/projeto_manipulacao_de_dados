## Sobre o Projeto

O projeto tem como objetivo realizar a **análise e comparação de dados provenientes de dois bancos de dados distintos**, utilizando SQL Server e PostgreSQL.

As bases possuem um grande volume de dados, tornando inviável analisar todo o seu conteúdo de forma indiscriminada. Por isso, será realizado inicialmente um **estudo de caso** para definir quais dados e análises são mais relevantes, considerando:

* Importância das informações;
* Presença de dados duplicados ou faltantes;
* Diferenças entre as bases;
* Custo computacional das análises;
* Impacto das análises na aplicação.

A partir desse recorte, serão realizadas **análises quantitativas e qualitativas** utilizando Python, buscando identificar inconsistências, diferenças e possíveis problemas de qualidade dos dados entre as duas fontes.

## Como Executar o Projeto

```bash
# Clonar o repositório
git clone <URL_DO_REPOSITORIO>

# Acessar o projeto
cd <NOME_DO_PROJETO>

# Instalar as dependências
pip install -r requirements.txt

# Executar o projeto
python <ARQUIVO_PRINCIPAL>.py
```

> As configurações de acesso aos bancos de dados deverão ser definidas conforme o ambiente de execução.
